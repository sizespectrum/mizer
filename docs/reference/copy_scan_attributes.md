# Copy the metadata of a MizerScan onto another object

Copy the metadata of a MizerScan onto another object

## Usage

``` r
copy_scan_attributes(to, from)
```

## Arguments

- to:

  The object to receive the attributes.

- from:

  The MizerScan to take them from.

## Value

`to` with the attributes and class of a MizerScan.
