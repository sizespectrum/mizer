# S4/S3 compatibility slot assignment helper

S4/S3 compatibility slot assignment helper

## Usage

``` r
slot(object, name, check = TRUE) <- value
```

## Arguments

- object:

  An object (S4 or S3).

- name:

  Name of the slot / list element.

- check:

  Logical.

- value:

  Value to assign.

## Value

The modified object.
