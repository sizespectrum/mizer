# Print a mortality decomposition report

Print a mortality decomposition report

## Usage

``` r
# S3 method for class 'MizerMortalityBreakdown'
print(x, ...)
```

## Arguments

- x:

  A MizerMortalityBreakdown object from
  [`getMortByCause()`](https://sizespectrum.org/mizer/reference/getMortByCause.md).

- ...:

  Unused.

## Value

The report, invisibly.
