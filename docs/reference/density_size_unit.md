# The size unit appearing in the units of a density

The size unit appearing in the units of a density

## Usage

``` r
density_size_unit(measure)
```

## Arguments

- measure:

  One of
  [density_measures](https://sizespectrum.org/mizer/reference/density_measures.md).

## Value

`"g"` or `"cm"`, or `NA_character_` for a density with respect to a
logarithmic size, whose units carry no size unit.
